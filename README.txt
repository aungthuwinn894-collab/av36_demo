AV36 App-style Demo (PWA)

This package is an installable web app prototype, not a native Android APK.
To install it on Android:
1. Upload/extract this folder to an HTTPS website host.
2. Open that HTTPS address in Chrome.
3. Open Chrome menu (⋮) and choose "Install app" or "Add to Home screen".
4. Follow the prompt. AV36 will appear as an app icon.

The demo contains no real-money betting, deposits, withdrawals, or redeemable credits.
